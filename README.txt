North Star Bakery Touchstone 3

This builds on the four HTML pages from Touchstone Task 2. All pages share styles.css. Supplied media files remain in media/. There is no JavaScript or build step. Open index.html in a browser or serve this directory with a static server.

Design: cream #FFF8F0, brown #6B3E26, peach #D88C5A, charcoal #2F2A26; Georgia headings and Arial body text. Mobile-first Flexbox layout with a 48rem breakpoint.

The contact form demonstrates browser validation only and does not deliver requests. Business details are illustrative student content.
